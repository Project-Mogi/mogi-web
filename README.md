# 기숙사 상벌점 관리 시스템

기숙사 사감선생님이 학생들의 상점과 벌점을 빠르고 직관적으로 관리할 수 있도록 만드는 관리자용 웹 서비스입니다.

반복적인 학생 관리 업무를 더 짧은 흐름으로 처리하고, 누적 상벌점 현황을 한눈에 확인할 수 있는 깔끔한 운영 도구를 목표로 합니다.

## 주요 기능

- 사감 계정 로그인
- 전체 학생 상벌점 현황 조회
- 학생 이름 검색
- 학년, 반 기준 필터링
- 학생별 상점/벌점 상세 조회
- 상점/벌점 등록, 수정, 삭제
- 대시보드 요약 지표
- 벌점 TOP 및 반별 통계

## 기술 스택

- React
- TypeScript
- Vite
- Styled Components
- React Router
- Zustand
- Axios
- React Query

## 디자인 방향

Toss Design System의 사용성을 참고해 단순하고 명확한 관리자 UI를 지향합니다.

- 넓은 여백
- 카드 기반 정보 구조
- 부드러운 radius
- 최소한의 색상 사용
- 큰 클릭 영역
- 명확한 상태 표시
- 반응형 레이아웃

## 아키텍처 방향

Feature-Sliced Design을 기준으로 화면, 기능, 도메인, 공통 리소스를 분리합니다.

```txt
src/
  app/
  pages/
  widgets/
  features/
  entities/
  shared/
```

## 개발 원칙

- TypeScript strict 모드 사용
- 재사용 가능한 컴포넌트 구조
- 디자인 토큰 기반 스타일 관리
- Styled Components ThemeProvider 사용
- 컴포넌트 내부 인라인 스타일 지양
- 서버 상태는 React Query로 관리
- 클라이언트 UI 상태는 Zustand로 관리
- 유지보수성과 확장성을 우선

## 개발 로드맵

1. 프로젝트 초기 세팅
2. 디자인 토큰 및 공통 UI 컴포넌트 구성
3. 라우팅과 전역 Provider 구성
4. 인증 및 API 클라이언트 구성
5. 학생 목록과 필터 구현
6. 상벌점 등록/수정/삭제 구현
7. 대시보드와 통계 화면 구현
8. 반응형 대응
9. 로딩, 에러, 빈 상태 처리
10. 사용성 개선 및 최적화

## 현재 상태

초기 설계 및 구현 준비 단계입니다. 공개 저장소에는 프로젝트 개요와 프론트엔드 구현 코드만 관리하며, 상세 API 명세와 내부 기획 문서는 별도로 관리합니다.
